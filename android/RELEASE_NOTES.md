## Acrux Mobile V1.2.0 Update
- Added a Biome tab — wireless debugging connection
  - Reading the biome from Roblox logs needs permission to read logs, so Acrux connects to this phone itself through Android's wireless debugging [ Android 11+, Wi-Fi needed ]
  - Pair once: [Start pairing] → Developer options → Wireless debugging → 'Pair device with pairing code' → with the code window open, enter the 6-digit code in the Acrux notification's [Enter code]
  - After that, just [Connect] while wireless debugging is on (connects automatically when the app opens) · the connection key is stored only inside the app
- Biome log test (step 1)
  - Checks whether mobile Roblox writes biome info to its logs like PC: 1. existing logs 2. log files in the Roblox folder 3. new logs for 90 seconds
