## Acrux Mobile V0.1.0 업데이트
- 안드로이드용 자동 낚시 [ Beta ] 첫 버전 (PC 버전 자동 낚시와 같은 판단 방식)
  - 자동 보정: 낚시 자리에서 [보정] 한 번 → 대기 창 · 미니게임 창 · 결과창 위치를 화면에서 찾아 맞춤 (해상도 · 화면 비율 상관없음)
  - Fish 던지기 → 입질 기다리기 → 릴링 → 결과창 닫기 · 결과 기록 (성공 · 쓰레기 · 실패)
  - 결과창이 다른 자리에 뜨면 X 를 화면에서 찾아서 누름 · 화면이 꼬이면 자동 복구
  - 터치 지연에 맞춰 기다리기 · 미리 누르기 (ms) 설정
- 로블록스 위에 떠 있는 작은 Acrux 창: [보정] · [시작] / [정지] · 끌어서 옮기기
- 필요한 권한: 접근성 (터치) · 화면 캡처 (화면 색 보기 · 녹화 · 저장 안 함)

## Acrux Mobile V0.1.0 Update
- First version of auto fishing [ Beta ] for Android (same detection as the PC auto fishing)
  - Auto calibration: tap [Calibrate] once at the fishing spot → finds the idle, minigame and result windows on screen (any resolution or aspect ratio)
  - Casts Fish → waits for a bite → reels → closes the result window · records results (success · junk · fail)
  - Finds the X on screen when the result window appears elsewhere · recovers automatically when the screen gets stuck
  - Waits according to touch delay · press-early (ms) setting
- Small floating Acrux window over Roblox: [Calibrate] · [Start] / [Stop] · drag to move
- Permissions: accessibility (touch) · screen capture (reads screen colors · never records or saves)
